Exit codes are the API

1
it ran and the answer was wrong
2
it could not run: unknown problem, missing toolchain, not signed in

Written for agents

The todo list is a queue anything can write to, so a script can stack up problems from a job description and they are waiting on the board next time you open it. Every operation is idempotent — adding twice is not an error, so nothing has to check before it acts.

submit is the one command with outside effects, and it says so. There is no push command at all. docs/AGENTS.md

Install
$go install github.com/Nano-AI/leetui/cmd/leetui@latest

Go 1.24+. Python, Go and C++ run on your machine; everything else runs on the judge. Cookies go to the OS keychain.
